# 🚚 Factory-to-Customer Shipping Route Efficiency Analysis for Nassau Candy Distributor

## 📌 Project Overview

The **Factory-to-Customer Shipping Route Efficiency Analysis** project is a Business Intelligence and Data Analytics solution developed to evaluate and optimize shipping operations for Nassau Candy Distributor.

The project transforms raw order and shipment data into meaningful operational insights using Python, Streamlit, Plotly, and Power BI. It enables stakeholders to monitor shipping performance, identify logistics bottlenecks, evaluate route efficiency, and improve decision-making through interactive dashboards.

---

# 🎯 Problem Statement

Nassau Candy Distributor ships products from multiple factories to customers across different regions of the United States.

The organization lacked visibility into:

- Efficient factory-to-customer shipping routes
- Frequently delayed routes
- Regional shipping performance
- State-level logistics bottlenecks
- Ship mode efficiency
- Product performance

Without these insights, logistics optimization remained reactive rather than data-driven.

---

# 🎯 Project Objectives

The primary objectives of this project are:

- Analyze shipping efficiency across all routes.
- Calculate shipping lead time.
- Identify the fastest and slowest shipping routes.
- Compare ship mode performance.
- Analyze geographical shipping patterns.
- Evaluate product performance.
- Build interactive dashboards for decision making.
- Provide business insights using visual analytics.

---

# 📊 Key Performance Indicators (KPIs)

The project tracks multiple business KPIs including:

- Total Sales
- Gross Profit
- Shipping Lead Time
- Average Lead Time
- Total Orders
- Route Volume
- Product Performance
- Ship Mode Performance
- Factory Performance
- Regional Performance
